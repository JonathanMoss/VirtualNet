# UI/UX Layout Specification: VirtualNet

This document defines the responsive layout structures (Bootstrap 5), interactive state indicators, and keyboard navigation configurations for the VirtualNet web client.

---

## 1. Grid Hierarchy & Layout Mockup

The user dashboard uses a two-column Bootstrap layout with a slide-out drawer:
- **Left Sidebar** (`col-md-3`): Online roster list and Net Control status panel.
- **Main Panel** (`col-md-9`): PTT transmission card and the scrollable interactive log table.
- **Right Margin Slide-out** (Off-canvas): Aide Memoire & Code Tools drawer.

## 2. Component Layout & Bootstrap Classes

### 2.1 Connect / Join Net Screen (Landing Page)
A centered clean container for student log in:
- Layout classes: `d-flex align-items-center justify-content-center min-vh-100 bg-dark`
- Card styled box:
  - **4-Character PIN**: Text input with constraint `maxlength="4"`, capitalizes characters, placeholder `e.g. A3F9`.
  - **Nickname**: Text input, constraint 1-20 characters, alphanumeric/spaces.
  - **Join Button**: `.btn .btn-success .w-100` (disabled until both inputs are populated).
- *Sub-text toggle link*: "Are you an Instructor? Create a Net" (links to 2.2).

### 2.2 Create Net Screen (Instructor Portal)
Centered card container for instructors to host a session:
- Input fields:
  - **Net Session Name**: Text input (e.g. `Exercise Alpha`).
- **Create Session Button**: `.btn .btn-primary .w-100`
- Upon creation:
  - Displays a large alert box with the **4-Character PIN** generated by the server.
  - Transition button to the **Instructor Dashboard**.

### 2.3 Instructor Dashboard Layout
A control center for the session:
- **PIN Display**: Persistent badge displaying `PIN: A3F9` in the top right.
- **Admissions Queue Panel**:
  - Styled as a table showing waiting students:
    - Columns: Nickname, Assign Callsign (input text box), Action button (`[Assign Callsign]`).
    - Inputting a callsign and submitting emits an `assign_callsign` event, shifting the student to the active net.
- **Active Roster Management Grid**:
  - Table showing all active students:
    - Columns: Callsign, Nickname, Role, State (Idle/Talking), Action Buttons (`[Kick]`).
- **Session Control**:
  - `[End Net Session]` Button: Styled with `.btn .btn-danger`. When clicked, terminates all connections and resets the server session.

### 2.4 Header Bar
Top navigation bar styled as a military command header:
- Layout classes: `navbar navbar-dark bg-secondary px-3 shadow-sm`
- Content:
  - Branding text: `VIRTUALNET` (Phonetic spelling reference toggle button on hover).
  - Quick-access button: `[📞 Net Allocation Summary]` (Triggers the Callsign Allocation popover modal defined in Section 2.7).
  - Global Net State badge:
    - Directed Net: `.badge .bg-danger` (Display: `DIRECTED NET`)
    - Free Net: `.badge .bg-success` (Display: `FREE NET`)
  - System Clock: Real-time Date-Time-Group text display (e.g., `281025Z JUL 26`).

### 2.5 Online Roster Sidebar (`col-md-3`)
A list group displaying all currently connected operators:
- Layout classes: `list-group list-group-flush shadow-sm bg-white p-2 rounded`
- Each list-item displays `Callsign (Nickname)`:
  - Control Station: Marked with a crown/star icon and class `.text-primary`.
  - Speaking Station: Highlighted with an active sound wave animation class `.bg-warning-subtle` and status badge `.badge .bg-danger` (`TALKING`).
  - Idle Station: Standard text with status badge `.badge .bg-light` (`IDLE`).
  - Muted Station: Icon of microphone-slash and status badge `.badge .bg-secondary` (`MUTED`).

### 2.6 PTT Control Panel (`col-md-9` top)
A prominent control card that serves as the visual interface of the transceiver:
- Layout classes: `card border-secondary mb-3 shadow-sm`
- UI States:
  - **AWAITING ASSIGNMENT**: Displays a full-card overlay spinner: `"Waiting for Instructor to assign your Callsign..."`. PTT button is hidden/disabled.
  - **IDLE STATE**: Gray border (`.border-secondary`). Instruction text: `"Press and hold SPACEBAR or click to transmit."`
  - **TRANSMITTING STATE**: Thick red border (`.border-danger .bg-danger-subtle`). Large pulsing indicator: `"● TRANSMITTING"` (`.text-danger`).
  - **RECEIVING STATE**: Thick orange/yellow border (`.border-warning .bg-warning-subtle`). Text: `"RECEIVING: R11 (John)"` (`.text-warning`).
  - **OVERRIDDEN STATE**: Flashing gray/black card (`.border-dark`). Warning sound triggers and text flashes: `"PTT OVERRIDDEN BY CONTROL"`.
- **Signal Quality Indicator**:
  - Displays a signal strength bar indicator reflecting the current `signal_quality` value:
    - `OK`: 3 bars (Green)
    - `DIFFICULT`: 1 bar (Yellow) + text: `"Weak Signal - Static Active"`
    - `UNWORKABLE`: 0 bars (Red, crossed out) + text: `"No Signal - Radio Link Failure"`
- **Logsheet View Toggle (Paper Mode)**:
  - Pinned directly above the Logsheet header is a button `.btn .btn-outline-info .btn-sm` with the text: `[📝 Screen Log: ON]` (or `[📝 Screen Log: OFF - Paper Mode]`).
  - Clicking this collapses/folds the digital logsheet container completely, leaving only PTT and roster panels visible. When collapsed, a watermark appears: `"Paper Logging Mode Active - Log on physical pad"`.

### 2.7 Callsign Allocation Summary Modal
Triggered by the button in the header bar.
- Styled as a Bootstrap Modal overlay (`.modal-content .shadow-lg`).
- Displays a clean, tabular summary of the net's callsign allocation map:
  - Table columns: `Call Sign`, `Assigned Nickname`, `Role`, `Connection Status`.
  - Also displays the fixed structural template (e.g. NCS = `0`, Squadron HQ = `10`, `20`, Section stations = `11`-`14`) for reference so students know how their call signs relate to the net structure.

## 3. Side-Sliding Aide Memoire Panel (Reveal & Fold)

Pinned to the right edge of the viewport is a vertical slide-out tab button (`.btn .btn-info .rounded-start` rotated vertically) displaying `[ 🗂️ AIDE MEMOIRE ]`.
- When clicked:
  - An off-canvas sidebar container slides out from the right (`380px` width) with class `.offcanvas-end .show`.
  - The main container slightly shifts or the panel overlays with a subtle backdrop.
  - Inside the drawer is a clean, multi-accordion panel structured into four main sections:

### 3.1 Logging Shorthand Symbols Cheat Sheet
A quick list of symbols students can copy down when writing on paper or screen:
- `0` / `CS 0` - Net Control Station
- `R` - Routine Precedence
- `P` - Priority Precedence
- `I` - Immediate Precedence
- `F` - Flash Precedence
- `C` - Contact Report (Initiated)
- `S` - Sighting Report
- `Z` - Zulu Time (GMT/UTC)
- `x` - Struck-off / Entry finalized
- `RPT` - Repeat requested / Say Again
- `OK` / `D` / `U` - Readability checks (OK, Difficult, Unworkable)

### 3.2 Interactive BATCO Tool Panel
A digital replication of the paper BATCO sheet:
- Displays the **Cipher Grid**: Scrambled letters mapped under plain text columns `0` to `9` and the special symbols.
- Features a **Movable Slider Ruler**: A highlighted row overlay (`.bg-info-subtle` or a bordered indicator frame) that the student can move up and down using arrow buttons or dragging.
- Alignment Settings display: Shows which columns are aligned (e.g. Column 2 Row I setting) for quick double-check.

### 3.3 Vocabulary Cards Directory
- Displays a dropdown selector containing **Cards 001 to 012** (Card 001 OPS 1, Card 002 OPS 2, etc.).
- Selecting a card displays a search-filterable table containing the substitution pairs.
  - E.g., Card 001: `00 = ADV`, `04 = AMBUSH`, `35 = MSN CFM`, `36 = MOVE TO GR (6 FIG)`.

### 3.4 Tactical Slate Cards (AC-71936)
A collection of fold-out forms styled like reference military slates. Clicking each slate's header un-folds/collapses the details:

- **NATO SITREP Card**
  - **A** (When?): DTG of situation
  - **B** (Own Loc?): Grid reference
  - **C** (What is happening?): Details of enemy
  - **D** (What are you doing?): Intentions/Actions
- **MIST (AT) Casualty Card**
  - **Zap No**: Anonymized ID
  - **M** (Mechanism of Injury)
  - **I** (Injury/Illness Sustained)
  - **S** (Symptoms & Vital Signs - MARCH checklist)
  - **T** (Treatment Given)
  - **A** (Age of casualty)
  - **T** (Time of wounding)
- **NATO MEDEVAC Card**
  - **Line 1**: Callsign & Freq
  - **Line 2**: HLS Location (Grid)
  - **Line 3**: Number of Patients by Precedence (P1 Priority, P2 Routine, P3 Low)
  - **Line 4**: Special Equipment (Hoist/None)
  - **Line 5**: Number of Patients by Type (Stretcher/Walking/Escort)
  - **Line 6**: Security at HLS (No Enemy, Enemy in Area, Armed Escort)
  - **Line 7**: HLS Marking (Panels, Smoke color, Pyro)
  - **Line 8**: Patient Nationality (Military, Civilian)
  - **Line 9**: Tactical Considerations
- **Fire Mission (Call for Fire) Card**
  - *"Fire Mission, Over"*
  - **A**: Target Location (Grid)
  - **B**: Direction (in mils)
  - **C**: Target Description
  - **D**: Nearest Friendly position
  - **E**: Effect required (Smoke, Illum, Harass, Destroy, Neutralize)
  - **F**: Duration (How long?)
  - **G**: Timing (When?)
- **QAOS (Quick Attack Orders Slate)**
  - **01**: Ground (Assault Route, Break-in point)
  - **02**: Enemy (Strength, weapons, position type)
  - **03**: ORBAT (Fire Support / Assault / Reserve groups)
  - **04**: Scheme of Manoeuvre (SoM)
  - **05-10**: Key Phases (FSP, POF, Break-in bound, LOE)
  - **11-13**: Fire Signals, FSCM boundaries, Combat ID marks
  - **16**: H Hr
- **JAMREP (Jamming Report)**
  - **A**: Type of jamming (Music, Tones, Carrier Wave, Noise, Voice)
  - **B**: Strength (Weak, Medium, Strong)
  - **C**: Mode (Responsive, Constant)
  - **D**: Affected Frequency
  - **E**: Location of Victim (Grid)
  - **F**: Time of Start & Duration
- **EQUIPRECREQ (Equipment Recovery)**
  - **A**: Recovery Location Grid
  - **B**: Vehicle details (Make, Model, Designation)
  - **C**: Vehicle problem (Stuck in ditch, engine failure)
  - **D**: Crew available (Yes/No)
  - **E**: Destination location
- **EOINCREP (Explosive Ordnance Incident)**
  - **1**: DTG of find
  - **2**: Reporting unit
  - **3**: Location of link-up (RV Grid)
  - **4**: Comms method
  - **5**: Description of EO
  - **6**: Location of EO (Grid)
  - **7**: Tactical situation
  - **8**: Damage / Threat
  - **9-10**: Actions taken & Recommended Priority (Immediate, Urgent, Routine)

## 4. Keyboard Focus Map & Logsheet Navigation

To achieve mouse-free logging during voice traffic, the radio log sheet forces strict tab-index paths and key handlers:

```
[Row N]   [Time] ──Tab──► [From] ──Tab──► [To] ──Tab──► [Precedence] ──Tab──► [Event Text] ──Tab──► [Initials] ──Enter──┐
                                                                                                                 │
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
│
└─► [Creates Row N+1] ──► Focus shifts automatically to [From] cell on Row N+1 (Time is auto-filled)
```

### Keyboard Event Behaviors
- **`Tab`**: Moves focus from cell to cell inside the active log row (`Time` -> `From` -> `To` -> `Precedence` -> `Event Text` -> `Initials`).
- **`Shift + Tab`**: Moves focus backward through the active row's cells.
- **`Enter` (pressed while editing the `Initials` cell)**:
  - Automatically triggers a SocketIO client-to-server sync event (`sync_log_entry`) to save the completed row.
  - Automatically appends a new blank row at the bottom of the table.
  - Instantly shifts keyboard focus to the `From` cell of the new row.
- **`Ctrl + N` (Global Shortcut)**: Creates a new blank row immediately and shifts focus to the first editable cell.

## 4. Military/Tactical Design System & CSS Guide

To replicate a realistic field radio terminal, the CSS styles override Bootstrap defaults with a tactical/CRT design system:

### 4.1 Color Palette
- **Primary Background**: Night-Ops Dark Slate (`#1A1D1A` to `#242824`) - mimics black anodized military equipment casing.
- **Containers & Cards**: Olive Drab Dark (`#2A2E2A`) - matches field radio containers.
- **Text & UI Indicators**:
  - Primary: Tactical Amber (`#FFB000`) or CRT Phosphor Green (`#33FF33`) - mimics monochrome cathode-ray tube displays.
  - Secondary: Desert Sand Tan (`#C2B280`) - for text labels and metadata.
  - Danger (PTT Active): High-intensity Red (`#FF3333`) - indicating hot-mic state.
- **Borders**: Tactical Olive/Tan (`#4E544E`).

### 4.2 Typography
- **Core Font**: Monospace family (`Roboto Mono`, `SFMono-Regular`, `Courier New`, or `monospace`).
- **Panel Headers**: Stencil-style fonts or capitalized monospace text with tracked-out spacing (e.g. `letter-spacing: 0.15em; font-weight: 700;`).

### 4.3 Borders & Cards
- **No Rounded Corners**: All components set `border-radius: 0 !important;` to resemble blocky, ruggedized hardware gear.
- **Borders**: Styled as thin, crisp, tactical grid lines (`1px solid #4E544E`).
- **CRT Scanline Filter Overlay (Optional)**: A subtle CSS linear-gradient background animation overlaying the PTT panel to simulate a scanline cathode screen.

### 4.4 Buttons & Interactive States
- **PTT Button**: Styled as a heavy, industrial red push-button (`.btn-danger`, with a dark inset box-shadow to look like a physical toggle).
- **Hover effects**: Subtle outline highlights and glow transitions (`box-shadow: 0 0 10px rgba(51, 255, 51, 0.4)` for green elements).

## 5. Mobile Responsiveness & Touch Interfaces

To ensure students can participate in net exercises on standard tablets or mobile phones, the client UI is fully responsive:

### 5.1 Collapsible Grid Layout (Bootstrap breakpoints)
- **Viewport Scaling**: Layout targets standard breakpoints (`sm`, `md`, `lg`).
- **Sidebar (Roster)**: On viewports `< 768px` (`col-12`), the Left Sidebar stacks underneath or collapses into a Left Off-Canvas drawer (`#rosterOffcanvas`), toggled by a `[👥 Roster]` button in the top navbar to save vertical space.
- **Main Panel**: Stretches to full width on mobile viewports.

### 5.2 Touch-Hold PTT Usability
- Since mobile devices lack physical spacebars:
  - The PTT button acts as a touch-hold button.
  - Client JavaScript binds to touch events:
    - **`touchstart`**: Initiates PTT request to the server (equivalent to `keydown`).
    - **`touchend` / `touchcancel`**: Releases transmission lock (equivalent to `keyup`).
  - Mobile web zoom and double-tap gestures are disabled on the PTT button to prevent lag or accidental release during touch-hold.

### 5.3 Mobile Logsheet Handling
- Grid tables are difficult to edit on small touchscreens:
  - The table container uses Bootstrap's `.table-responsive` class to enable smooth horizontal touch scrolling.
  - **Paper Mode Recommendation**: On screens `< 576px`, a warning badge appears suggesting: `"Paper Mode Recommended on Mobile. Tap above to collapse log sheet"`.
  - Alternatively, adding a new log row displays a simple mobile form modal (`.modal`) rather than inline cell input to make editing easy.

### 5.4 Slide-Out Drawers on Mobile
- The off-canvas Aide Memoire / Code Tools panel (`offcanvas-end`):
  - On viewports `< 576px`, the width shifts from `380px` to `100vw` (full screen width), ensuring the BATCO grid and vocabulary cards are fully legible.
